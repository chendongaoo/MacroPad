# MacroPad
A 6 key and 1 rotary encoder macropad designed so I can learn pcbs.

This was my first time ever doing a hardware project involving PCBs so I would say this was a really educational and fun experience!

# Firmware
QMK Firmware was used in order to make the firmware of the macropad. I was able to let it have my 6 keys type different letters out and also have the rotary encoder be for volume.
